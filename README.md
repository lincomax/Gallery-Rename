# Fossify Gallery (Rename Button Restored)

<img alt="Logo" src="graphics/i.png" width="120" />

A custom build of Fossify Gallery that can be installed alongside the original. This fork stays identical to upstream Fossify Gallery except for reverting the part of pull request [#909](https://github.com/FossifyOrg/Gallery/pull/909) that barred the Rename action button from appearing in the top right of the photo viewer.

That change removed a layout option that had been possible since 2016, long before Fossify forked from the original Simple Gallery. Users unwilling or unable to adapt to this change have been stuck using outdated versions of Gallery without all the great work that Fossify continues to do. Ideally, it will one day revert the change, and this fork won't be necessary.

You can show your support for this feature being returned to the main Fossify Gallery app by giving a thumbs up on [this issue](https://github.com/FossifyOrg/Gallery/issues/1023).
